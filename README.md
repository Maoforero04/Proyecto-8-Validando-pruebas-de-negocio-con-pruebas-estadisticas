# Proyecto-8-Validando-pruebas-de-negocio-con-pruebas-estadisticas
Análisis de un experimento A/B en una landing page (versiones A y B): pruebas t, z y chi-cuadrado sobre conversión, gasto, canales de tráfico y tipo de usuario, con visualizaciones e insight ejecutivo para apoyar una decisión de negocio basada en datos.
